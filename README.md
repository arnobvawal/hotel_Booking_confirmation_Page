# Maison Soleil Guest Guide

This project is a responsive hotel booking confirmation page inspired by the Frontend Mentor challenge for a boutique stay in Cassis. It presents a warm, editorial-style guest experience with a receipt card, welcome note, itinerary details, and quick-access information panels.

## Overview

The page is built as a static landing experience focused on guest onboarding and hotel details. It includes:

- a responsive two-card booking layout
- a fixed sidebar navigation for room and guest information
- a printable receipt section
- a Wi-Fi password copy interaction with user feedback
- warm, custom-styled typography and illustrations for a premium boutique-hotel feel

## Challenge context

This implementation follows the UX direction of the [Hotel booking confirmation page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/hotel-booking-confirmation-page), while adapting the visual language with an original palette, custom illustrations, and a more editorial layout style.

## Features

- Mobile-first, responsive layout
- Sticky navigation and guest card interactions
- Print receipt action for the booking summary
- Copy-to-clipboard for the guest Wi-Fi password
- Local assets and custom fonts for a polished, self-contained design

## Project structure

- `index.html` — page structure and content
- `js/script.js` — print and copy interactions
- `src/input.css` — Tailwind source styles
- `src/output.css` — generated CSS used by the page
- `images/` — icons, illustrations, and brand assets
- `fonts/` — local font files used in the design

## Getting started

Install dependencies:

```bash
npm install
```

Run the Tailwind watcher during development:

```bash
npm run dev
```

Validate the JavaScript and rebuild the CSS bundle:

```bash
npm test
```
